# 海风骑行 · 鹈鹕的慢游日记

可交互三维海岸骑行网页。

功能：踩踏与车轮联动、围巾、海浪、海鸟、灯塔、帆船；暂停和调速、追随/侧面/环绕镜头、拖拽缩放、晴日/日落/月夜、车色、环境音、车铃、拍照、纯净模式、全屏。

本地开发：安装 Node.js（脚本运行环境），在此目录执行 `npm install`（安装依赖），再执行 `npm run dev`（启动开发服务）。
构建：`npm run build`（生成静态网站），结果位于 dist（成品目录）。

技术：Three.js（三维引擎）0.186.1、Vite（构建工具）6.4.3、Lucide（图标库）0.468.0。所有三维模型和声音均由程序生成，不调用收费生成接口，成品无外部运行时资源依赖。

交互快捷键：空格暂停/继续，B（车铃键）鸣铃，Esc（退出键）离开纯净模式。

验证范围：桌面与手机尺寸浏览器验证；未覆盖实际手机硬件、所有运营商网络及扬声器音质。
